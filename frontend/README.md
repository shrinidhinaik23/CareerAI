# CareerAI Frontend

Frontend for CareerAI — an AI-powered resume analysis and career guidance platform.

## Features
- Resume upload UI
- ATS score display
- Job match analysis
- Skill gap insights
- Career recommendations
- Interview question generation
- Cover letter generation
- LinkedIn optimization
- Payment integration
- Chatbot support

## Tech Stack
- React.js
- JavaScript
- CSS
- Axios
- Firebase

## Run Locally
```bash
npm install
npm start
